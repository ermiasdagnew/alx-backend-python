Django-signals_0x04 - Minimal project containing messaging app with signals, models, and caching.
To run:
1. Create a virtualenv and install Django (e.g., pip install django).
2. cd /mnt/data/alx-backend-python/Django-signals_orm-0x04
3. python manage.py migrate
4. python manage.py createsuperuser
5. python manage.py runserver
